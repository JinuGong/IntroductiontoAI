# 07. 딕셔너리와 집합

## 학습 목표
- 딕셔너리에 값을 추가/조회/수정/삭제한다.
- `keys`, `values`, `items`, `get` 메서드를 활용한다.
- `for key, value in d.items():` 패턴을 능숙하게 사용한다.
- 집합으로 중복 제거 및 합/교/차집합 연산을 수행한다.

## 핵심 개념
- **딕셔너리**: 키-값 매핑 구조 (해시 테이블 기반)
- **집합**: 중복 없는 모음, 순서 없음
- **`d[key]` vs `d.get(key)`**: 전자는 KeyError 발생, 후자는 None 반환
- **집합 멤버십 검사**: O(1) 시간 복잡도

## 실습 프로젝트
1. 단어 빈도 분석기
2. 편의점 재고 관리
