# 07. 딕셔너리와 집합

## 🎯 학습 목표
- 딕셔너리에 값을 추가/조회/수정/삭제할 수 있다.
- `keys`, `values`, `items`, `get` 메서드를 활용한다.
- `for key, value in d.items():` 패턴을 자연스럽게 쓴다.
- 집합으로 중복 제거와 합/교/차집합 연산을 한다.

## 📖 핵심 개념
- **딕셔너리** = 키 → 값 매핑 (해시 테이블)
- **집합** = 중복 없는 모음, 순서 없음
- `d[key]` 는 키 없으면 KeyError, `d.get(key)` 는 None
- `set` 의 멤버십 검사는 O(1)

## 🛠️ 실습 프로젝트
1. 단어 빈도 분석기
2. 편의점 재고 관리
