# 09. 파일 입출력

## 학습 목표
- `open()` 함수로 파일을 읽고 쓴다.
- `with` 구문으로 안전하게 파일을 처리한다.
- `csv` 모듈로 CSV 파일을 읽고 쓴다.
- `csv.DictReader`로 헤더 기반 접근을 수행한다.
- 한글 파일의 인코딩 문제(`utf-8` vs `cp949`)를 해결한다.

## 핵심 개념
- **`with open(...) as f:` 패턴**: 권장하는 파일 처리 방식
- **`'w'` 모드 경고**: 기존 파일을 전체 덮어쓰기 - 주의 필요
- **CSV 쓰기 옵션**: `newline=''` 권장 (Windows 줄바꿈 중복 방지)
- **인코딩 오류**: `UnicodeDecodeError` 발생 시 다른 인코딩 시도
