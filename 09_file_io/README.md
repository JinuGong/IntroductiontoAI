# 09. 파일 입출력

## 🎯 학습 목표
- `open` 함수로 파일을 읽고 쓸 수 있다.
- `with` 구문으로 안전하게 파일을 다룬다.
- `csv` 모듈로 CSV 파일을 읽고 쓸 수 있다.
- `csv.DictReader` 로 헤더 기반 접근을 할 수 있다.
- 한글 파일의 인코딩 문제(`utf-8` vs `cp949`)를 이해한다.

## 📖 핵심 개념
- `with open(...) as f:` 패턴은 항상 권장
- `'w'` 모드는 기존 파일을 **덮어쓴다** — 주의
- CSV 쓰기 시 `newline=''` 을 권장 (윈도우 줄바꿈 중복 방지)
- 인코딩 안 맞으면 `UnicodeDecodeError` — 다른 인코딩 시도
