# 06. 리스트와 튜플

## 🎯 학습 목표
- 리스트를 만들고, 원소를 추가/수정/삭제할 수 있다.
- 인덱싱과 슬라이싱 (`lst[a:b:c]`) 을 자유롭게 쓸 수 있다.
- `sort`, `sorted`, 그리고 정렬 옵션을 활용할 수 있다.
- **참조 vs 복사** 의 차이를 이해한다.
- 리스트 컴프리헨션을 작성할 수 있다.
- 튜플의 특징(불변)을 이해한다.

## ⚠️ 자주 하는 실수
- `a = b` 후 한쪽을 바꿔도 다른 쪽이 안 바뀔 거라고 오해 → **참조** 임
- `lst.sort()` 는 `None` 을 반환 (제자리 정렬). `sorted(lst)` 는 새 리스트
- `remove()` 는 첫 매칭만 삭제 — 전부 지우려면 컴프리헨션
