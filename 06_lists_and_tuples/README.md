# 06. 리스트와 튜플

## 학습 목표
- 리스트를 생성하고 원소를 추가/수정/삭제한다.
- 인덱싱과 슬라이싱 (`lst[a:b:c]`)을 활용한다.
- `sort`, `sorted` 및 정렬 옵션을 적용한다.
- 참조(reference)와 복사(copy)의 차이를 이해한다.
- 리스트 컴프리헨션을 작성한다.
- 튜플의 불변성(immutability)을 이해한다.

## 주의사항
- **`a = b` 이후 수정**: 참조 관계 유지 - 한쪽 수정 시 다른 쪽도 영향받음
- **`lst.sort()` 반환값**: `None` 반환 (제자리 정렬). `sorted(lst)` 사용 시 새 리스트 반환
- **`remove()` 메서드**: 첫 번째 일치 항목만 삭제 - 모두 제거하려면 컴프리헨션 사용
