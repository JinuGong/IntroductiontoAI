# 01. 변수와 자료형

## 학습 목표
- `print()` 함수로 값을 출력한다.
- 주석을 활용하여 코드를 설명한다.
- `int`, `float`, `str`, `bool` 자료형을 구분한다.
- `int()`, `float()`, `str()` 함수로 자료형을 변환한다.
- 따옴표 종류와 이스케이프 시퀀스를 이해한다.

## 핵심 개념
- **변수**: 값을 저장하기 위한 이름표
- **자료형 추론**: Python은 대입된 값을 기반으로 자료형을 자동 결정
- **형 변환**: 호환되지 않는 자료형 간의 명시적 변환 처리
