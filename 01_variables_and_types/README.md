# 01. 변수와 자료형

## 🎯 학습 목표
- `print()` 로 값을 출력할 수 있다.
- 주석을 사용해 코드를 설명할 수 있다.
- `int`, `float`, `str`, `bool` 자료형을 구분할 수 있다.
- `int()`, `float()`, `str()` 로 자료형을 변환할 수 있다.
- 따옴표 종류와 이스케이프 시퀀스를 이해한다.

## 📖 핵심 개념
- **변수**: 값을 담는 이름표
- **자료형 추론**: 파이썬은 대입된 값으로 자료형을 자동 결정
- **형 변환**: 자료형이 맞지 않으면 명시적으로 바꿔야 함
