# 02. 연산자

## 학습 목표
- 산술/비교/논리/비트 연산자를 구분하고 활용한다.
- 복합 할당 연산자(`+=` 등)를 적용한다.
- `and/or`의 단락 평가(short-circuit) 개념을 이해한다.
- 논리 연산(`and`)과 비트 연산(`&`)의 차이를 구분한다.

## 핵심 개념
- **`//` vs `/`**: 정수 나눗셈 vs 실수 나눗셈
- **`%`**: 나머지 연산 - 짝/홀 판정 및 단위 변환에 활용
- **단락 평가**: `and/or`는 마지막 평가 값 자체를 반환
- **비트 연산**: 2진법 기반의 이진 연산

## 연습문제
노트북 마지막 셀 참조
