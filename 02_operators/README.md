# 02. 연산자

## 🎯 학습 목표
- 산술/비교/논리/비트 연산자를 구분하고 사용할 수 있다.
- 복합 할당 연산자(`+=` 등)를 활용할 수 있다.
- `and/or` 의 단락 평가(short-circuit)를 이해한다.
- 논리 연산(`and`)과 비트 연산(`&`)의 차이를 안다.

## 📖 핵심 개념
- **`//` vs `/`** : 몫 vs 일반 나눗셈
- **`%`** : 나머지 — 짝/홀, 단위 변환에 자주 쓰임
- **단락 평가** : `and/or` 는 마지막 평가 값 자체를 반환
- **비트 연산** : 2진법으로 생각

## ✏️ 연습문제
노트북 마지막 셀 참고.
