# 03. 입력과 모듈

## 학습 목표
- `input()` 함수로 사용자 입력을 받고 적절한 자료형으로 변환한다.
- `split()`, `map()` 함수로 여러 값을 한 번에 입력받는다.
- `random` 모듈로 난수 생성 및 무작위 선택을 구현한다.
- `math` 모듈의 주요 함수와 상수를 활용한다.

## 핵심 개념
- **`input()` 반환값**: 항상 문자열 타입 - 숫자로 사용하려면 `int()`, `float()`로 변환 필수
- **모듈 호출**: `import 모듈` 후 `모듈.함수()` 형태로 호출
- **`random.randint(a, b)`**: 양 끝 포함 / **`random.randrange(b)`**: b 미만

## 연습문제
노트북 마지막 셀: 헤론의 공식을 이용한 삼각형 넓이 계산
