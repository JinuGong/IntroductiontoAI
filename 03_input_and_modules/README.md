# 03. 입력과 모듈

## 🎯 학습 목표
- `input()` 으로 사용자 입력을 받고 적절한 자료형으로 변환할 수 있다.
- `split()`, `map()` 으로 여러 값을 한 번에 받을 수 있다.
- `random` 모듈로 난수 / 무작위 선택을 구현할 수 있다.
- `math` 모듈의 주요 함수와 상수를 활용할 수 있다.

## 📖 핵심 개념
- **`input()` 의 반환값은 항상 문자열** — 숫자로 쓰려면 `int()`, `float()` 으로 변환
- **`import 모듈`** 후 `모듈.함수()` 형태로 호출
- `random.randint(a, b)` 는 양 끝 포함, `random.randrange(b)` 는 b 미만

## ✏️ 연습문제
노트북 마지막 셀: 삼각형 넓이 (헤론의 공식).
