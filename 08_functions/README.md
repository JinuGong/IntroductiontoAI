# 08. 함수

## 🎯 학습 목표
- `def` 로 함수를 정의하고 호출할 수 있다.
- `return` 으로 값을 돌려주고 여러 값을 한 번에 반환할 수 있다.
- 디폴트 인자와 위치/키워드 인자의 차이를 안다.
- 변수 스코프와 `global` 의 동작을 이해한다.
- 재귀 함수의 종료 조건을 작성할 수 있다.
- `lambda` 를 정렬, 매핑에 활용할 수 있다.

## 📖 핵심 개념
- **매개변수 (parameter)** vs **인자 (argument)**
- `return` 없는 함수는 `None` 반환
- 함수 안에서 만든 변수는 **지역(local)** — 밖에서 접근 불가
- 디폴트 인자는 **뒤쪽**에 위치해야 함
