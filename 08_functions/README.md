# 08. 함수

## 학습 목표
- `def`로 함수를 정의하고 호출한다.
- `return`으로 값을 반환하고 여러 값을 동시에 반환한다.
- 기본 인자와 위치/키워드 인자의 차이를 구분한다.
- 변수 스코프와 `global` 키워드의 동작을 이해한다.
- 재귀 함수의 종료 조건을 작성한다.
- `lambda`를 정렬과 매핑에 활용한다.

## 핵심 개념
- **매개변수 (parameter)**: 함수 정의 시 명시된 변수
- **인자 (argument)**: 함수 호출 시 전달되는 실제 값
- **`return` 미지정**: `None` 반환
- **함수 내 변수**: 지역(local) 스코프 - 함수 외부에서 접근 불가
- **기본 인자 위치**: 필수 인자 이후에 위치해야 함
