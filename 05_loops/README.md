# 05. 반복문

## 학습 목표
- `for` + `range`로 횟수가 정해진 반복을 작성한다.
- `while`로 조건 기반 반복을 작성하고 무한 루프를 방지한다.
- `break`, `continue`로 반복 흐름을 제어한다.
- `for-else` / `while-else`의 동작을 이해한다.

## 핵심 개념
- **`range(start, stop, step)`**: stop은 미포함, step 방향 주의
- **`while` 루프**: 조건 갱신을 필수적으로 수행해야 함
- **`break` 동작**: 가장 가까운 반복문 하나만 즉시 종료

## 실습 프로젝트
1. 1~100 홀수 합 계산 (3가지 방식)
2. 비밀번호 확인 루프
3. 숫자 맞히기 (시도 횟수 제한)
4. Hangman 게임
5. 베스킨라빈스 31 게임
