# 04. 조건문

## 학습 목표
- `if`, `elif`, `else` 구조와 동작을 이해한다.
- 들여쓰기로 코드 블록을 구성한다.
- 여러 조건을 효율적으로 처리한다 (`elif` vs 연속 `if`).

## 핵심 개념
- **`:` (콜론)과 들여쓰기**: 코드 블록 구성의 필수 요소
- **`elif` 동작**: 앞 조건이 거짓일 때만 검사 - 위에서부터 첫 번째 참인 경우만 실행
- **조건 평가**: `bool` 타입으로 평가되는 모든 표현식을 조건으로 사용 가능

## 실습 프로젝트
1. 학점 계산기
2. 사칙연산 계산기
3. BMI 측정기
4. 복권 번호 매칭
5. 숫자 맞히기 (단일 시도)
