# 04. 조건문

## 🎯 학습 목표
- `if`, `elif`, `else` 의 구조와 동작을 이해한다.
- 들여쓰기로 코드 블록을 구분할 수 있다.
- 여러 조건을 효율적으로 분기할 수 있다 (`elif` vs 연속 `if`).

## 📖 핵심 개념
- **`:` (콜론)** 과 **들여쓰기** 가 블록을 만든다.
- `elif` 는 "앞 조건이 거짓일 때만 검사" — 위에서부터 첫 번째 참만 실행
- 조건은 `bool` 로 평가되는 모든 표현식 가능

## 🛠️ 실습 프로젝트
1. 학점 계산기
2. 사칙연산 계산기
3. BMI 측정기
4. 복권 매칭
5. 숫자 맞히기 (단발)
