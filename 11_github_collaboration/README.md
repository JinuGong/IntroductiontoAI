# 11. GitHub 협업 워크플로우

## 🎯 학습 목표
- git과 GitHub의 차이를 설명할 수 있다.
- 혼자 작업 흐름과 팀 작업 흐름의 차이를 안다.
- 브랜치를 만들고, 작업하고, PR로 머지할 수 있다.
- 충돌(merge conflict)을 두려워하지 않고 해결할 수 있다.
- 실수했을 때 `reflog`, `reset`, `revert` 로 복구할 수 있다.

## 📖 핵심 개념
- **GitHub Flow** : main + feature branch + PR
- **main 직접 커밋 금지** — 항상 브랜치에서
- **작업 전·후 `git pull`** — 동료 변경 동기화
- **작은 PR + 좋은 설명** — 리뷰받기 쉽게
- **`--force` 는 마지막 수단** — `--force-with-lease` 권장
